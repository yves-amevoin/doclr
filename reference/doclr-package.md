# doclr: R Client for the 'docling-serve' REST API

A pure-R, tidyverse-oriented client for the 'docling-serve' document
conversion REST API. Submits documents by URL or by file upload,
synchronously or asynchronously, polls long-running tasks and returns
results as a document object that can be rendered to Markdown, plain
text, HTML, JSON or DocTags. Includes optional helpers to provision and
manage a local 'docling-serve' container. No Python runtime is required.
